# Колесо мотивации

Мини-игра проекта «История и котики». Крутишь колесо и получаешь фразу поддержки. Часть фраз — чистая мотивация, часть — с успехами героев истории («Суворов не проиграл ни одного сражения, а ты ещё лучше!»).

На колесе 5 тем по 4 фразы, всего 20. Сначала выпадают ещё не открытые фразы. Фразу можно скопировать. Всё в одном файле `index.html`, без сборки.

## Как выложить на GitHub Pages

1. В аккаунте historyandcats создай репозиторий `koleso` (Public).
2. Add file → Upload files → загрузи `index.html` и `README.md` → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты игра откроется по адресу https://historyandcats.github.io/koleso/
